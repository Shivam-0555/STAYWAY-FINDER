# STAYWAY FINDER

A student-focused platform to find hostels, PGs,
budget food, ATMs and other useful places around campus.

## Features
- Find nearby hostels and PGs
- Search student-friendly places
- Interactive map
- Location-based listings
- Student-focused interface

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- OpenStreetMap

## Live Demo
[https://stayway-finder.vercel.app]

## Installation

git clone YOUR_REPOSITORY_URL
cd stayway-finder
npm install

## Environment Variables

Create a .env.local file and add required variables.

## Run Locally

npm run dev
